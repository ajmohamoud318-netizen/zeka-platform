# Zeka Kızları Platform

## Overview

Internal project management system for Yükselen Zeka.

**Users**

- Team Leader
- Designers
- Manager (view only)

## Core Features

- Project creation
- Assign designers
- Page-based progress tracking
- Kapak / Kutu / Medya components
- **Status flow:** New → Active → Demo → Ozalit Onay → Üretim → Satış → Completed

## Rules

- Designers cannot change status
- Designers cannot change total page count
- Manager is read-only
- Team Leader controls everything

## Progress

Based on:

- Completed pages
- Kapak / Kutu / Medya completion

## Ozalit Approval

**Three approvals**

- Team Leader
- Designer Approver
- Printer

**Rules**

- All must approve to move forward
- If one rejects:
  - Stay in Ozalit
  - Can reset approvals
  - Can move back to Demo
